= Personal Records Vault

Local-first, user-held structured personal records with hooks for verifiable credentials, multi-modal indexing, and selective disclosure toward providers and employers.

The primary application shell is an **Electron + SolidJS** desktop app (cross-platform installers). A **WebExtension** companion targets Chromium (Chrome, Edge) and Firefox (MV3). An optional **D** CLI remains under `native/cli` for experiments, not the main UI.

WARNING: This repository is experimental research software. It is not a medical device, not a HIPAA compliance product, and not legal advice about health records in your jurisdiction.

== Provider SDK (care software developers)

* **OpenAPI:** link:spec/openapi/prv-local.openapi.yaml[`spec/openapi/prv-local.openapi.yaml`] — generate Java, C#, Python, Go, and other clients from this file.
* **JSON Schema:** link:spec/json-schema/exchange-bundle.schema.json[`spec/json-schema/exchange-bundle.schema.json`] — bundle payload validation.
* **TypeScript reference:** link:packages/sdk/README.adoc[`packages/sdk` (`@prv/sdk`)] — `createVaultClient({ baseUrl })` for loopback HTTP calls.

Build the SDK with `pnpm --filter @prv/sdk build` (also runs as part of `pnpm build` at the repo root).

== Prerequisites

* https://nodejs.org/[Node.js] 22.x (see also `packageManager` in link:package.json[package.json])
* https://pnpm.io/[pnpm] 9.x (Corepack can install the pinned version)

== Desktop app (Electron + Solid)

[source,powershell]
----
pnpm install
pnpm dev
----

Production bundle (Vite output under `apps/desktop/out`):

[source,powershell]
----
pnpm build
----

Installers (NSIS on Windows, DMG on macOS, AppImage on Linux) via https://www.electron.build/[electron-builder]:

[source,powershell]
----
pnpm dist
----

Artifacts land in `apps/desktop/release/`.

== Browser extension

Build output is written to `apps/extension/dist/`.

[source,powershell]
----
pnpm build:extension
----

Load unpacked:

* *Chrome / Edge:* `chrome://extensions` or `edge://extensions` → Developer mode → *Load unpacked* → select `apps/extension/dist`.
* *Firefox:* `about:debugging#/runtime/this-firefox` → *Load Temporary Add-on* → pick `apps/extension/dist/manifest.json`.

== Optional D CLI

[source,powershell]
----
Set-Location native/cli
dub build
dub run
----

== CI and releases

* link:.github/workflows/ci.yml[CI] builds the desktop and extension bundles on Ubuntu.
* link:.github/workflows/release-desktop.yml[Release desktop] runs on `workflow_dispatch` and on tags matching `v*` to produce per-OS installers and upload GitHub Actions artifacts.

Codesigning and macOS notarization are not configured yet; expect unsigned macOS binaries until you add certificates and entitlements.
